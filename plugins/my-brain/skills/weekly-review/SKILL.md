# Weekly review

1. Read every file in `projects/`. For each, list status, last stop, next step. Flag any with no next step.
2. Read every file in `people/`. Flag anyone whose "Last contact" is older than 30 days from today.
3. Ask me if any decisions were made this week; append them to `decisions.md`.
4. Write the result to `notes/weekly-review-YYYY-MM-DD.md` (today's date).

Do not invent content. If a file is missing information, list it under "Gaps".
